Glosario de Data 360

Términos clave resumidos a partir del glosario oficial de Salesforce Help.

🎯 Objetivos del módulo (según la guía oficial del examen)
  • Dominar el vocabulario oficial.

📖 Términos Glosario

TérminoSignificado
ActivationProceso que publica un segmento a plataformas de activación (targets).
Activation membershipAgrupación de campos de varios DMO que se incluye en una activación.
Activation targetDestino con su autenticación donde se envían los datos del segmento.
Attribute Library Metadata (ALM)Modelo de todas las relaciones entre objetos del data graph; define los caminos disponibles para segmentar y activar.
Calculated Insight (CI)Herramienta que consulta, transforma y calcula sobre datos almacenados.
Calculated Insight Object (CIO)DMO creado tras procesar un CI.
CategoryAgrupación de tipos de datos elegida al importar (Profile, Engagement, Other); no editable tras la ingesta.
ChunkingTrocear datos no estructurados antes de vectorizarlos.
Clean roomEntorno seguro para colaboración de datos sin compartir los datos en bruto.
Communication cappingUmbrales que limitan la frecuencia de contacto.
Composite keyClave primaria formada por varios campos.
Contact pointCampo(s) que permiten contactar a un individuo (email, teléfono).
Customer 360 Data ModelModelo canónico de Data 360.
Data action / targetAcción disparada por un streaming insight (o cambios) y el registro con credenciales del destino.
Data bundleConjunto de data streams mapeados automáticamente a DMO.
Data Cloud OneConecta orgs compañeras con una home org de Data 360.
Data federationConsultar fuentes externas sin copiarlas: query federation (live/accelerated) y file federation.
Data graphVista materializada precalculada de DMO combinados.
Data kitPaquete portátil de metadatos.
Data lake object (DLO)Contenedor para los datos ingestados.
Data mappingAsociar DLO a DMO.
Data model object (DMO)Agrupación de atributos del modelo; estándar o custom; virtual o físico.
Data shareColección de DLO/DMO/CIO consultable sin mover datos.
Data spacePartición lógica de datos, metadatos y procesos.
Data streamFuente de datos traída a Data 360, batch o streaming.
Data transformCombinar, limpiar y preparar datos dentro de Data 360.
Dimension / MeasureValor cualitativo de categorización / valor cuantitativo agregado.
Document AIExtracción de campos estructurados desde documentos con LLM.
EnrichmentConsulta o copia datos de Data 360 a una org (copy fields, related lists).
External DLOContenedor de metadatos que apunta a datos federados.
Fully qualified key (FQK)Clave compuesta de clave origen + key qualifier.
HarmonizationMapear datos ingestados al modelo Customer 360.
Hybrid searchCombinación de búsqueda por palabras clave y vectorial con fusion ranker.
Identity resolutionCasar y reconciliar datos de personas en perfiles unificados mediante rulesets.
Intelligent ContextEspacio guiado por prompts para configurar search indexes.
Key qualifierValor que identifica la fuente en un campo de clave.
Match rules / Reconciliation rulesVinculan registros / eligen el valor ganador.
Primary key / Foreign keyIdentificador único / campo que refiere a la clave primaria de otra tabla.
Private ConnectConectividad privada con sistemas externos.
Profile ExplorerHerramienta para ver Unified Individuals.
Query EditorHerramienta para ejecutar SQL.
Retriever (dynamic / ensemble)Capa de recuperación reutilizable para RAG; con filtros dinámicos o combinando varios.
RulesetCombinación de match y reconciliation rules.
Segment OnEntidad sobre la que se evalúa un segmento.

Fuentes: help.salesforce.com «Data 360 Glossary of Terms» (parafraseado y resumido).
