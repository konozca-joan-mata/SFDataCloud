🧪 8.2 Ejemplos ilustrativos

# Ingestion API (streaming) — patrón. Rutas y versión: verifica en Developer docs
curl -X POST "$DC_TENANT/api/v1/ingest/sources/<source_api_name>/<object_name>" \
  -H "Authorization: Bearer $DC_TOKEN" -H "Content-Type: application/json" \
  -d '{"data":[{"id":"1001","email":"ana@example.com","created":"2026-11-02T10:00:00Z"}]}'
# Límites: 200 KB por petición (403 si se excede) y 250 req/s en total (429)
-- Streaming transform ilustrativo: normalizar email al llegar
SELECT
  id__c,
  LOWER(TRIM(email__c)) AS email_clean__c,
  created__c
FROM Customers_Stream__dll
Los sufijos de API name son __dll (DLO), __dlm (DMO) y __cio (CIO) ⚠ verificar.

📦 8.3 ALM y calidad

Despliegue Help⚠ verificar

  • Data kit en el data space por defecto → Package Manager → org destino.
  • Máx. 50 objetos por operación de guardado en un kit; transforms ligadas a data spaces no por defecto no se despliegan con kit.
  • Prueba en sandbox: mapeos, rulesets y segmentos con datos representativos.
  • Versiona OpenAPI schemas y SQL de insights/transforms en Git.
