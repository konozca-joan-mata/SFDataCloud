🗃️ P.2 Datos: formatos y SQL mínimo

FormatoQué esDónde lo verás
CSVTexto con columnas separadas por comas, primera fila = cabeceraCargas de ficheros
JSONDatos anidados con llaves y corchetesIngestion API, data graphs
APIForma de que un programa hable con otro por HTTPIngestion API, Query API

SQL es el lenguaje para consultar tablas. Con tres ideas cubres el 80 % de lo que verás en Data 360:

-- Tabla ficticia: orders(customer_email, amount_eur, channel)
SELECT customer_email, SUM(amount_eur) AS gasto   -- 1) elegir columnas y agregar
FROM orders                                          -- 2) de qué tabla
WHERE channel = 'web'                                -- 3) filtrar filas
GROUP BY customer_email                              -- 4) una fila por cliente
ORDER BY gasto DESC;

JOIN une dos tablas por una clave: orders JOIN customers ON orders.customer_email = customers.email. Los calculated insights y los transforms de Data 360 son, en esencia, SELECT con GROUP BY y JOIN.

🧪 Autoevaluación

¿Qué es un objeto y qué es un registro?

Objeto = tabla; registro = fila (P.1).

¿Qué hace GROUP BY?

Agrupa filas para calcular agregados (SUM, COUNT…) por grupo (P.2).

¿Qué diferencia hay entre un CRM y un data warehouse?

CRM opera procesos con clientes; el warehouse almacena y analiza grandes volúmenes (P.3).

¿Qué es una activación?

Enviar un segmento a un canal o plataforma (P.4).

¿Qué es un sandbox?

Una copia de pruebas de la org (P.1).
