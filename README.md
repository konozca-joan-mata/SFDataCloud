# Salesforce Data Cloud (Data 360) Knowledge Hub

Formación completa de **Salesforce Data Cloud / Data 360** para perfiles Consultant y Developer, alineada con la guía oficial del examen *Salesforce Certified Data 360 Consultant* (Spring '26).

👉 Abre **[START.html](./START.html)** en el navegador.

## Cómo se estudia
- **Desde cero:** P → 0 → 1 → … → 6 → ★ (caso integrador) → 7 → 8 → 9 → 12, en *Modo aprender*.
- **Repaso:** *Modo repaso* (botón en cada página) oculta explicaciones y laboratorios.
- Cada módulo: *para entender* → referencia oficial → errores típicos → laboratorio → repaso exprés → preguntas.
- `datasets/` contiene los CSV de práctica.

## Fiabilidad
Cada dato indica su fuente: Help, Trailhead, Glosario, Developer docs o guía del examen. Lo no verificado va marcado como «⚠ verificar». Los límites y nombres cambian con cada release: contrasta siempre con Salesforce Help.

## Fuentes sin acceso
