🧪 Ingesta

🧪 Autoevaluación

¿Qué categoría usas para datos de clic con timestamp?

Engagement.

¿Qué pasa si quieres cambiar la categoría de un stream?

No se puede; hay que recrear el stream.

Dos ERP usan el mismo ID para clientes distintos. ¿Qué evitas con qué?

Conflictos de clave, usando key qualifiers / fully qualified keys.

¿Qué límite de payload tiene Ingestion API streaming?

200 KB por petición (403 si se excede).

¿Cuándo usar Zero Copy en lugar de ingestar?

Cuando los datos están en un DWH/lakehouse y debe evitarse copiarlos; con la latencia de consulta aceptable.

¿Diferencia entre query federation live y accelerated?

Live consulta en tiempo de ejecución sin guardar nada; accelerated usa una caché local refrescada periódicamente.

¿Qué transform usar para unir varios DLO con editor visual y programación?

Batch transform.
